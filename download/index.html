How to install

  1. Tap Download APK and allow the download to finish.
  2. Open the downloaded APK. Android may ask you to allow your browser to install apps from this source.
  3. Allow that permission when prompted, then return to the APK and install Necpra.
  4. After installation, open Necpra and sign in normally.

Important for future updates

Keep the existing Android application identity com.necpa and sign every future APK with the same release key. That lets an existing installation update instead of being treated as a different application.

The Android shell is configured to load the live Necpra website, so normal web application updates do not require a new APK. A new APK is needed when the native Android shell itself changes.

The APK is delivered through the Necpra backend download service. GitHub remains the private release source, but users do not need a GitHub account.
